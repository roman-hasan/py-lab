## Job Application Screening System

An application that evaluates job applicants based on their qualifications, experience, skills, and interview performance to make hiring decisions and determine salary offers.

### Features

- Candidate Assessment
- Hiring Decision
- Rejection & Hold Reason Explanation
- Salary Offer Calculation
- Final Assessment Report

### Concepts Used

- Variables & Data Types
- Strings & User Input
- Operators
- Conditions

**Version:** `v1.1.0`
